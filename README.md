# Mohammed Khan SRE Portfolio

Personal SRE / DevOps portfolio site built with React and Vite.

## Local development

```powershell
npm install
npm run dev
```

## Production build

```powershell
npm run build
```

## Deploy to GitHub Pages

Create a GitHub repository, add it as `origin`, then run:

```powershell
npm run deploy
```

In GitHub repository settings, set Pages to deploy from the `gh-pages` branch.
